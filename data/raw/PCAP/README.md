Set each Google Drive file to **Anyone with the link: Viewer** before downloading.

## Download

Download each file from its Drive link and place it in this directory. Then verify the checksums:

```bash
md5 Monday-WorkingHours.pcap
md5 Wednesday-workingHours.pcap
```

The output should match the MD5 values in the table above.
